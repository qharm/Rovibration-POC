class rovib.molecule.Molecule(symbols, coords, masses)

The user’s description of a (non-linear) molecule.

This class is a stand-in for SimDE’s ChemicalSystem class. The coordinates and masses are stored as read-only arrays.

Parameters:

  • symbols (tuple of str) – The atomic symbol of each atom.

  • coords (numpy.ndarray) – Cartesian coordinates of each atom in bohr. The shape is (number of atoms, 3).

  • masses (numpy.ndarray) – Isotopic mass of each atom in electron masses. The shape is (number of atoms,).

Raises:

ValueError – If coords or masses does not have the shape implied by symbols.

class rovib.rovibrational_basis_function.RovibrationalBasisFunction(v: tuple, J: int, K: int)

A rovibrational basis function \(\ket{\vvec,J,K}\).

The basis function is the product of one harmonic oscillator eigenfunction per vibrational mode and an angular momentum eigenstate. Instances are immutable and hashable.

Parameters:

  • v (tuple of int) – The vibrational quantum number of each mode.

  • J (int) – The total angular momentum quantum number.

  • K (int) – The projection of the total angular momentum on to the molecule-fixed z-axis.

Raises:

ValueError – If any vibrational quantum number is negative, if J is negative, or if \(|K| > J\).

property nvib

The number of vibrational modes.

Return type:

int

class rovib.rovibrational_ansatz.RovibrationalAnsatz(nvib, vmax, J)

The space in which the Hamiltonian is diagonalized.

The space is the direct product of harmonic oscillator states, with \(0 \le v_k \le v_{\max}\) for every mode, and the angular momentum states \(\ket{J,K}\) with \(K = -J, \ldots, J\) for a single \(J\). Only the truncation parameters are stored; basis functions are generated on demand.

Basis functions are ordered with the first mode’s quantum number varying slowest and \(K\) varying fastest.

Parameters:

  • nvib (int) – The number of vibrational modes.

  • vmax (int) – The maximum vibrational quantum number of each mode.

  • J (int) – The total angular momentum quantum number.

Raises:

ValueError – If nvib is less than 1 or if vmax or J is negative.

class rovib.hamiltonian_term.HamiltonianTerm

Base class for the terms of a Hamiltonian.

Terms carry the state needed to evaluate their matrix elements, but otherwise serve as a domain-specific language for specifying which terms are in the Hamiltonian. Matrix elements are evaluated by separate functions (see rovib.hamiltonian_matrix).

Adding two terms, or a term and a Hamiltonian, gives a Hamiltonian.

Defines the Hamiltonian class.

Matrix Elements

Matrix elements of the harmonic oscillator Hamiltonian.

\(\HHO\) is diagonal in the rovibrational basis:

\[\braket{\vvec',J',K'\mid\HHO\mid\vvec,J,K} = \delta_{\vvec',\vvec}\delta_{J',J}\delta_{K',K} \sum_{i=1}^{\Nvib}\omega_i\left(v_i + \frac{1}{2}\right)\]

in atomic units.

rovib.harmonic_hamiltonian_elements.harmonic_non_zero_indices(bra_space, term, ket_space)

Generates the bra-ket pairs with non-zero matrix elements of \(\HHO\).

Since \(\HHO\) is diagonal, an element is non-zero only if the bra and ket are the same basis function.

Parameters:

  • bra_space (RovibrationalAnsatz) – The space the bra basis functions come from.

  • term (HarmonicHamiltonian) – The harmonic oscillator Hamiltonian.

  • ket_space (RovibrationalAnsatz) – The space the ket basis functions come from.

Returns:

A generator of (bra, ket) pairs of RovibrationalBasisFunction objects.

Return type:

collections.abc.Iterator

Raises:

ValueError – If either space has a different number of vibrational modes than term.

Builds the matrix of a Hamiltonian in a rovibrational ansatz.

non_zero_indices() and matrix_element() are the common APIs for all Hamiltonian terms; internally they dispatch on the type of the term. build_hamiltonian_matrix() uses them to fill in the non-zero elements of a dense matrix.

Parameters

Hard-coded parameters for water.

Unless noted otherwise, the parameters are from Appendix B of E. Lötstedt and T. Szidarovszky, J. Chem. Phys. 165, 024118 (2026), doi:10.1063/5.0333947. The functions in this module return the parameters in atomic units.

The molecule-fixed axes are those of the paper: x (the paper’s a axis) is perpendicular to the molecular plane, y (b) is in the plane, and z (c) is the C2 axis. The atoms are ordered O, H1, H2, and the vibrational modes are ordered symmetric stretch, bend, antisymmetric stretch.

This file was generated by Claude. RMR has verified that the parameters in this file are consistent with 10.1063/5.0333947.

rovib.water_params.water_molecule()

Returns the equilibrium geometry of water.

The paper only gives the O-H distance and the H-O-H angle. The Cartesian coordinates are derived from them, with the center of mass at the origin and the axes described in the module documentation.

This fixes the coordinates up to the sign of the inversion \(\rzvec \rightarrow -\rzvec\), which the Eckart conditions cannot determine. The orientation used here has O on the -z side of the center of mass and H1 at y < 0, which is the orientation that reproduces the paper’s results. Note that, with the paper’s normal-mode matrix, a positive displacement along the symmetric stretch then compresses the O-H bonds.

Returns:

Water at its equilibrium geometry.

Return type:

Molecule
