Library Design

Considerations

  1. Should be extensible to other molecules. But will be hard-coded to water for now.

    • Main feature gap is getting the anharmonic force constants.

  2. First pass is a standalone Python module. Eventually will want to go back and modularize it for use with SimDE.

    • Envisioning a top-level driver where each subfunction will eventually be a PluginPlay module.

  3. First pass will build entire Hamiltonian matrix.

    • This is not scalable. Eventually want to do Davidson diagonalization so will need to be able to do sigma builds.

  4. Will use atomic units for all calculations.

  5. Need complex arithmetic because matrix elements of P and J are complex.

  6. Object-oriented.

    • Classes discussed in Classes Design section.

  7. One class per Hamiltonian term.

    • Like SimDE, terms should carry state needed to evaluate matrix elements, but serve primarily as a DSL for determining what terms are in the Hamiltonian.

  8. Need a class for describing the space in which the Hamiltonian will be diagonalized.

    • Carries parameters to denote how the basis is truncated.

    • Also DSL-like. Storing full basis is not scalable.

  9. Driver responsible for going from a molecule to a Hamiltonian operator to the eigenvalues of the Hamiltonian operator.

Driver Control Flow

  1. Input is a minimum energy Molecule object.

    • Hard-code to water in the system test.

    • Assuming minimum energy allows focusing on Taylor expanding the PES.

  2. Do harmonic analysis to get \(\Lvec\) and \(\omegavec\).

  3. Fill HarmonicHamiltonian object.

    • Hard-code for water. Throw if input Molecule is not water.

    • A general approach needs second derivatives of the electronic energy with respect to displacements from \(\rzvec\).

  4. Fill AnharmonicPotential object.

    • Hard-code for water. Throw if input Molecule is not water.

    • A general approach needs third and fourth derivatives of the electronic energy with respect to displacements from \(\rzvec\).

  5. Fill RigidRotorHamiltonian object.

    • Build the inertia tensor and diagonalize it.

    • Test against hard-coded values for water.

  6. Build the eta tensors.

    1. Compute \(\avec\).

      • \(\Nvib\) by 3 by 3

      • Needs \(\rzvec\), \(\Mvec\), and \(\Lvec\).

    2. Compute \(\Bvec\) by transforming \(\avec\) using \(\Izvec\).

      • \(\Nvib\) by 3 by 3

    3. Build the five eta tensors from \(\Bvec\) and \(\Izvec\).

      • n = 0 is 3 by 3

      • n = 1 is 3 by 3 by \(\Nvib\)

      • n = 2 is 3 by 3 by \(\Nvib\) by \(\Nvib\)

      • n = 3 is 3 by 3 by \(\Nvib\) by \(\Nvib\) by \(\Nvib\)

      • n = 4 is 3 by 3 by \(\Nvib\) by \(\Nvib\) by \(\Nvib\) by \(\Nvib\)

  7. Build WatsonHamiltonian object.

  8. Compute \(\zetavec\).

    • \(\Nvib\) by 3 by \(\Nvib\)

    • Involves cross-products of \(\Lvec\).

  9. Build RovibrationalHamiltonian and VibrationalCoriolisHamiltonian

    • Input is \(\zetavec\) and \(\etavec\).

  10. Build RovibrationalAnsatz object.

    • Input is the maximum vibrational quantum number and total angular momentum.

  11. Build the Hamiltonian in the RovibrationalBasisFunction basis.

    • Details are in Evaluating Matrix Elements section.

  12. Diagonalize the Hamiltonian matrix to get eigenvalues/eigenvectors.

    • Driver returns the eigenvalues and eigenvectors
